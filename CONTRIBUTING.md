# Contributing to Awesome Startup Ideas

Thanks for helping. This list is different from most awesome lists: **every entry is ranked by data**, so the rules are strict.

## What we accept

* **Corrections.** A number looks wrong, a link is broken, a category is mislabeled. Open an issue with what you saw.
* **New startup idea spaces** that can be backed by a public, checkable number (paying customers, product counts, revenue, complaint volume). Include the source.
* **Better guides.** If you wrote an in-depth, data-backed guide to one startup niche, suggest it as a link under that niche.

## What we do not accept

* Ideas with no number behind them. Brainstorms belong somewhere else.
* Affiliate links, course sales pages or "get rich" content.
* Boilerplate, starter-kit or template promotions.
* Manual edits to the ranked sections of `README.md`. Those sections are generated.

## How the README is built

The ranked sections are generated from a monthly data snapshot. The data is refreshed monthly by [BigIdeasDB](https://bigideasdb.com/?utm_source=github&utm_medium=awesome-startup-ideas&utm_campaign=contributing).

## Style

* One line per idea: name, link, then the numbers.
* Counts are rounded down with a `+` (for example `430+ products`).
* No em dashes. Keep descriptions short and factual.
